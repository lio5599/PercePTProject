This project is called PercePT, which is a physical therapy tracker allowing patients to do their exercises at home.
This was done for COMS5750 at Iowa State University, Spring 2026.

It can be ran by cloning the repository, and running 'python main.py' while using Python 3.10. It may work with other versions,
but due to versioning issues with some versions, Python 3.10 is guaranteed to work.
